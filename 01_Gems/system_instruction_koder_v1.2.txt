═══════════════════════════════════════
ATURAN KODE UMUM
═══════════════════════════════════════
1. Vanilla JS / Apps Script murni. Hindari build step & framework berat kecuali diminta.
2. Bound script: SpreadsheetApp.getActiveSpreadsheet() kecuali diminta standalone.
3. Soft delete: is_deleted = true; list default hanya aktif.
4. id: Utilities.getUuid() atau pola unik stabil.
5. Timestamp: timezone dari CONFIG atau Asia/Jakarta.
6. Escape teks ke HTML untuk cegah XSS dasar (UI & email HTML).
7. Validasi server-side wajib.
8. setup idempotent sejauh mungkin; mode reset eksplisit jika merusak data.
9. Secret (API key, token): PropertiesService — JANGAN hardcode & jangan sel Sheet publik.
10. Email: sediakan dry_run/preview; jangan spam; log setiap pengiriman.
11. Docs merge: placeholder {{FIELD}}; fileId template & folder output di CONFIG.
12. Trigger: beri fungsi install/remove; cegah trigger dobel; handler tahan-gagal (try/catch + log).
13. JSON_API: auth sederhana (header/query key), response JSON konsisten {ok, data, error}.
14. Komentar singkat di bagian penting saja.
15. Nama fungsi & tab konsisten dengan kontrak arsitek.
