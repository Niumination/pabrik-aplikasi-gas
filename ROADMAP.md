## Visi

Satu akun Google = **pabrik solusi berulang**:

```
Brief + gambar → Gem Analis → Blueprint + KEMASAN
     → Gem Koder → Artefak (Sheet/Script/HTML/Docs/Email/API)
     → Live → Factory Log
```

## Decision tree (ringkas)

1. Input lapangan/HP? → **WEB_APP** atau **FORM_ROUTER**  
2. Output PDF/dokumen? → **DOC_GENERATOR**  
3. Dorong lewat notifikasi? → **EMAIL_REPORT**  
4. Konsumen sistem lain? → **JSON_API**  
5. Hidup di Sheet? → **SHEET_ENGINE**  
6. Banyak modul? → **HYBRID_SUITE**  

Versi interaktif ada di HTML.

## Risiko utama

Kuota script/mail · Sheet non-transaksional · link publik · AI salah skema · single account · overpromise domain kritis.  
Mitigasi detail: bagian Risiko di HTML + `Rencana_Pabrik_Aplikasi_Ekosistem.md`.

## Cara pakai dokumen ini

1. Buka **`Roadmap_Pabrik_Aplikasi.html`** di Chrome/Edge/Firefox.  
2. Ikuti **Timeline** + centang checklist.  
3. Pakai **Pilih Kemasan** sebelum brief ke Analis.  
4. Filter **Produk** saat memilih build berikutnya.  
5. Lakukan langkah akun di **`USER_BAGIAN_SAYA.md`**.  
6. Opsional: Cetak/PDF dari browser (tombol di hero).
